# N-ZONE Guard 발표용 웹 프레젠테이션

GitHub Pages에 바로 올릴 수 있는 단일 HTML 프레젠테이션입니다.

## 사용법
- `index.html`을 브라우저로 열면 바로 실행됩니다.
- 키보드 `← / →`, `PageUp / PageDown`, `Space`로 이동합니다.
- `F` 키 또는 우측 하단 `⛶` 버튼으로 전체화면 전환합니다.
- 좌측 하단 3분 타이머는 클릭하면 다시 03:00부터 시작합니다.

## GitHub Pages 배포
1. 저장소 최상위(root)에 `index.html`을 업로드합니다.
2. GitHub 저장소 → **Settings → Pages**
3. **Source: Deploy from a branch**
4. **Branch: main / (root)** 선택 후 Save
5. 잠시 후 `https://계정명.github.io/저장소명/` 주소로 접속할 수 있습니다.
